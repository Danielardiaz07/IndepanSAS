# Glosario

| Término | Definición |
|---------|------------|
| Insumo | Producto que la tienda vende a panaderos/reposteros (harina, levadura, moldes…) |
| Producto | Entrada del catálogo con nombre, descripción, imagen, unidad y precio |
| Unidad de venta | Forma en que se vende un producto: kg, lb, g, saco, caja, bolsa, unidad, etc. Varía por producto |
| Paso de cantidad | Incremento permitido del selector (p. ej. 0.5 kg, 1 saco) |
| Carrito | Lista temporal de productos elegidos, guardada en `localStorage` |
| Pedido | Carrito + datos del cliente + entrega, enviado como mensaje de WhatsApp |
| Recogida | El cliente retira en la tienda |
| Domicilio | Entrega en la dirección del cliente |
| Site config | Archivo único con datos del negocio (nombre, WhatsApp, dirección, horarios…) |
| Catálogo | Archivo local tipado con todos los productos |
